## Bugs / Abweichungen

### BEOBACHTUNG: Testplan-Diskrepanz VER-05 (Reset active→draft)

- **Testplan:** „Reset (editor)" — impliziert editor-Berechtigung für active→draft
- **Code (`version_status.py` Zeile ~41):** Transition FROM `active` (inkl. active→draft) erfordert `admin`
- **Verhalten:** Editor bekommt 403 auf `transition to=draft` von einem aktiven Zustand
- **Bewertung:** Code-Verhalten ist korrekt und konsistent (Publish und Reset beides admin).
  Der Testplan ist irreführend. **Kein Bug** — aber Testplan-Korrektur empfohlen.

### BEOBACHTUNG: `link_scope='resource'` + `block_id` → 422

- `link_scope='resource'` verbietet `block_id` (Pydantic-Validator, `resource.py`).
  Dokumentation im Testplan (FT-PB-07) nennt `block_id` ohne diese Einschränkung — unklar.
  Beides getestet und korrekt abgebildet.
