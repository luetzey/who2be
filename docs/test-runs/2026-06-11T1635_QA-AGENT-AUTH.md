**Behebung für künftige Läufe:**
1. Environment mit Docker-Support nutzen (lokaler Dev-Container oder Hetzner)
2. `docker compose up -d --wait` ausführen → alle Services healthy
3. Integrationstests mit `WHO2BE_REQUIRE_DB=1 uv run pytest -q` wiederholen (erzwingt hartes Fehlschlagen statt stillem Skip in CI)
