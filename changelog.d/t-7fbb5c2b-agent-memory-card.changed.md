- The memory card on the agent page now uses the same list as the "Entries"
  tab of the memory page (learning loop C5b-2, memory management spec §6.6).

  It shows only this agent's entries, with search, sorting, a filter sheet
  (the agent itself is fixed and not offered as a filter) and the same row
  and bulk actions as the central list. Approvals no longer happen on the
  agent page: when entries are awaiting approval, a hint with the count
  links to "Awaiting approval", pre-filtered to this agent. The card shows
  how full the memory is ("N of 500 entries", "N of 200 agent notes", with
  "nearly full" from 90 %), and "Delete all" moved into the card's overflow
  menu with a confirmation that names the number of entries. "Open in memory
  management" carries the agent and the active filters over. When memory is
  off for the agent, existing entries stay readable without actions. Viewers
  do not see the card.
