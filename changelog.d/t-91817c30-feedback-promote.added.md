- **Altes Feedback wird Fall.** On the feedback item page, editors get „In Fall übernehmen“ next to the status segments while the feedback is still open (not yet triaged); system reports keep their own path. It opens the case form with the old note quoted as „Ausgangspunkt“ and the feedback's agent preselected (still changeable). The case is created via `POST /feedback/{feedback_id}/promote`; afterwards the feedback shows „Erledigt“ with the server's reference in its history, and the page offers a „Zum Fall“ link.
