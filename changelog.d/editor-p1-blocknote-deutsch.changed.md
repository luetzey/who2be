  Seitenmenü, Link-Leiste, Platzhalter) folgt jetzt der UI-Sprache. Bisher war

  Verweise“. Ein Sprachwechsel wirkt, sobald der Editor das nächste Mal
  geöffnet wird.

  Tests wörtlich prüfen.
