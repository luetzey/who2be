- **Fall-Detail: Triage und Prüffall aus Fall.** Editors see a „Nächster Schritt“ bar on a case with exactly one primary action per status (assign, triage, create test case, mark as addressed with a chosen version, go to version), plus a status menu for changing the assignment, dismissing and reopening (reason ≥ 10 characters). The assign dialog groups persona, playbooks, resources, tools, system prompt and memory of the agent, plus tool permissions and "model limit"; below `md` it is a bottom sheet with accordion groups. „Prüffall daraus anlegen“ opens the test-case form prefilled with the case's situation, expected behaviour and origin. A new „Verknüpft“ card lists test cases from the case, the source learning suggestion/feedback and the run link (only http(s) becomes a link). After a transition the focus moves to the status; a refused transition shows a notice and reloads the case.
