- **Muster im Feedback-Hub.** Editors get a new „Muster“ tab between „Fälle“ and „Bausteine“. It lists what the server computes from `GET /patterns` (optionally filtered by agent via `?agent=`): repeated learning suggestions („Dieselbe Korrektur n×“) and open cases on the same element („Ähnliche Fälle n×“), with the threshold taken from the response. Patterns have no status and cannot be dismissed. Clicking one opens a sheet (`?pattern=`) with the counting rule, the evidence (first 20, then „Alle n Belege anzeigen“, deleted entries marked), an ID-only Builder prompt to copy, and „Fall anlegen“ (lesson patterns) or „Fälle ansehen“ (case patterns). A pattern that no longer applies closes the sheet with a notice. Viewers don't see the tab.
