- Creating an agent: "Create new agent" now opens Settings › Configuration
  directly with the cursor in "Persona". When you save an agent that has a
  persona and a system prompt but is still deactivated, Who2Be asks "Activate
  the agent now?". "Activate" switches it on through the existing update route
  and jumps to the "Connection" card in the overview; "Later" leaves it
  deactivated. Members who cannot change the status (viewers) and managed
  agents get no prompt.
