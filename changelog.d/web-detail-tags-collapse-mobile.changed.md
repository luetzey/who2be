- Auf dem Handy (unter 768 px) zeigen die Detailseiten von Resource, Tool
  und Persona im Kopf nur drei Tags. Die übrigen liegen hinter einem Knopf
  „+n“, der sie aufklappt („Weniger anzeigen“ klappt sie wieder ein). Bei
  einer Resource mit 12 Tags rücken die Tabs bei 390 px von 762 auf 614 px
  hoch. Ab 768 px ändert sich nichts.
