# apps/web

React/TypeScript-Web-UI fuer Who2Be (Vite).

Phase 0: Vite-Grundgeruest. Login, Liste und simpler Detail-Editor folgen
als P1 — Funktion vor Schoenheit.

## Befehle

```bash
npm ci         # Dependencies
npm run dev    # Dev-Server
npm test       # Tests (vitest)
npm run lint   # ESLint
npm run build  # Production-Build
```
